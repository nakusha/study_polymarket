1-4스마트 컨트랙트 📜

블록체인 위에서 자동 실행되는 프로그램. 조건 맞으면 사람 없이 코드가 작동.

🥤 자판기 비유 — 1,000원 넣고 버튼 → 콜라 나옴. 누구도 "돈만 먹고 안 줄게" 할 수 없어요. 규칙이 기계에 박혀 있으니까.

  • 신뢰 불필요 — 운영자 안 믿어도 코드가 보장
  • 변조 불가 — 배포되면 코드를 못 바꿈

2-BCTF — 티켓 제조 공장

🎫 놀이공원 티켓 자판기처럼 3개 버튼: split · merge · redeem

split

1 USDC → Yes 1 + No 1

돈을 티켓 세트로

merge

Yes 1 + No 1 → 1 USDC

세트를 다시 돈으로

redeem

이긴 토큰 → $1

결과 후 당첨금

모든 토큰은 잠긴 USDC로 100% 담보 → 줄 돈이 항상 보장
가장 중요한 법칙
Yes+No =$1

세트(Yes+No)는 언제든 $1로 교환되니, 두 가격의 합은 항상 $1. 깨지면 차익거래가 즉시 메워요.

그래서 → 가격 = 시장이 보는 확률

2-D가격 = 확률

0.70
"70% 확률" · 맞으면 +43%
0.50
"반반" · 맞으면 +100%
0.20
"가능성 낮음" · 맞으면 +400% 😮

싸게 살수록 = 시장이 낮게 봄 = 맞으면 대박·틀리면 0원. 비싸게 = 거의 확실·안전.

2-E거래 — 결과를 안 기다려도 된다

주식 단타처럼 중간에 되팔기 가능.

[월] Yes 10주 @ 0.50 매수  →  -$5.00
[수] 태풍 뉴스 → Yes 0.70 상승 → @ 0.70 매도  →  +$7.00
결과: 비가 오든 말든 → +$2.00 확정 💰

숏(하락 베팅) = 반대편 No를 사면 끝. 복잡한 빌려오기 불필요.

2-E차익거래 — 등식을 지키는 힘 ⚖️

일반 사용자는 하나만 산다. 차익거래는 가격이 깨졌을 때 둘 다 사는 기술.

오더북: Yes 0.60 + No 0.30 = 0.90 ⚠️ 비정상
① 둘 다 매수 (-$0.90)  ② merge → $1.00 환불
결과: 무위험 +$0.10 — 봇이 달려들어 합이 1로 수렴

시장이 알아서 Yes+No=$1을 유지하는 자동 균형 장치

2-E자동 민팅 — 🍕 피자 비유

"Yes 사자" + "No 사자"가 만나면? → 둘의 돈을 합쳐 즉석에서 새 토큰 발행.

Alice: 왼쪽 반쪽(Yes) $0.60  +  Bob: 오른쪽 반쪽(No) $0.40
가게(거래소): $1 모아 피자 한 판 만듦 (split=민팅 🍕) → 반쪽씩 분배
두 매수자 = 합치면 "예치자 한 명". 별도 예치 불필요!

가능한 이유 = Yes+No=1이라 두 매수가 합이 정확히 세트 1개 값
